# Зафиксированная простая логика обновления

Без хэшей, кэша и сравнения версий.

Каждый запуск:

1. Скачивает прайс Росско по одной и той же ссылке.
2. Перезаписывает `input/rossko_price.xlsx`.
3. Формирует новый `public/drom_lensk.xlsx`.
4. Перезаписывает старый файл для Дрома.
5. Дром забирает файл по постоянной ссылке.

Единственная проверка: не затирать рабочий файл, если вместо Excel скачалась HTML-страница ошибки или пустой файл.
