## Что делать

1. Сохранить два тестовых XLSX из пакета чата (названия начинаются с `TEST_2_`).
2. В кабинете Авито Pro зайти в «Автозагрузка», выбрать загрузку Excel. **Убедиться, что кабинет позволяет безопасно проверить файл.** Если сервис начинает немедленную публикацию, это уже реальная публикация четырёх предложений.
3. Сначала загрузить только два файла по 2 товара, не `REVIEW_25_`.
4. Посмотреть отчёт Авито: синтаксис, обязательные поля, категории, пригодность фотографий и количество созданных объявлений.
5. Прислать отчёт ошибок/скриншот в чат; исправить генератор в этой ветке GitHub и повторно загрузить файлы с **теми же ID**.
6. Только после успешного теста и перепроверки применимости расширять пробную партию до всех 50.

Ничего не публикуется из GitHub Actions автоматически, расписание для Авито не включено. Рабочая выгрузка Дрома и ветка `main` не менялись.

`avito_xml_v3_diagnostic.py` получает данные из проверочного CSV после новой загрузки свежего прайса РОССКО; workflow `avito_xml_diagnostic.yml` создаёт временные XML-артефакты для четырёх товаров, **без** настройки публичного URL, расписания или автопубликации.
