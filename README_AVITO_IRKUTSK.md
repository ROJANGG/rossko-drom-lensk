# Авито — Иркутск: предварительный отбор

Новая независимая функция проекта. Существующий `update_prices.py` и загрузка Дрома не меняются.

## Условия

- Только **рулевые рейки** и **тормозные диски**, без сопутствующих деталей.
- Только РОССКО, **Иркутск**, и явно указанный срок поставки **0 дней**.
- Наличие строго больше нуля; закупочная цена положительная.
- Цена рассчитывается общей функцией проекта: наценка 37% и округление вверх до 50 ₽ (при текущей конфигурации).
- Один товар на пару бренд + артикул.
- Ошибка источника, неподходящий файл или устаревший локальный прайс останавливают обработку (без резервного старого прайса).

## Запуск

```bash
pip install -r requirements.txt
python avito_irkutsk.py --confirm-irkutsk-source
```

Подтверждение источника следует ставить **только если** ссылка из `config.json` действительно даёт складские остатки РОССКО по Иркутску. Если в XLSX нет явного поля склада, код не может доказать принадлежность остатков Иркутску. Результат: `output/avito_irkutsk_candidates.csv`.

## Что дальше

Это **черновик**, не отправляемый в Авито. Пользователь прислал два XLSX-шаблона Авито (тормозная система и рулевое управление). Следующий этап: подстановка строго проверенных товаров в эти шаблоны с указанием настоящего адреса продавца, фотографий с правом использования, состояния и совместимости автомобилей. Для тормозных дисков применимость обязательна по шаблону. Нельзя считать товары на складе РОССКО товарами в наличии непосредственно у продавца. Прежде чем включать регулярную выгрузку, надо спроектировать снятие объявлений при нулевом остатке и проверить результат импорта в Авито.

`output/avito_irkutsk_candidates.csv` и цены не следует публиковать в GitHub Pages.
