# Оригинальные шаблоны Авито

Поместите сюда без изменений два файла XLSX от 13 октября 2026 года:

- `Для автомобилей - Тормозная система - Шаблон 13-10-2026.xlsx`
- `Для автомобилей - Рулевое управление - Шаблон 13-10-2026.xlsx`

Их исходные файлы пользователь передал в чате; в GitHub их пока нет. Скрипт `avito_feed.py` открывает эти файлы по путям, указанным в `config.json`, сохраняет первые четыре строки и справочники, добавляет только проверенные объявления начиная со строки 5. Не помещайте сюда реальные прайсы или персональные данные покупателей.
