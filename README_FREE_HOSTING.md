# Бесплатный вариант размещения: GitHub Actions + GitHub Pages

Идея: GitHub по расписанию запускает скрипт, скрипт скачивает свежий прайс Росско, формирует `public/drom_lensk.xlsx`, а Дром забирает файл по постоянной ссылке GitHub Pages.

## Как это будет работать

1. Код лежит в репозитории GitHub.
2. В настройках GitHub хранится ссылка Росско `ROSSKO_PRICE_URL`.
3. GitHub Actions запускает обновление по расписанию или вручную.
4. Файл `public/drom_lensk.xlsx` перезаписывается.
5. В Дром указывается постоянная ссылка на этот файл.

## Что нужно сделать

1. Создать репозиторий на GitHub.
2. Загрузить в него содержимое папки `rossko_drom_auto_link_v04`.
3. В Settings → Secrets and variables → Actions добавить secret:

```text
ROSSKO_PRICE_URL
```

Значение — ссылка Росско на скачивание прайса.

4. В Settings → Pages включить публикацию из ветки `main`, папка `/root`.
5. После первого запуска файл будет доступен по ссылке примерно такого вида:

```text
https://USERNAME.github.io/REPOSITORY/public/drom_lensk.xlsx
```

Именно эту ссылку нужно указать в Дром Базе.

## Ручное обновление

В GitHub: Actions → Update Drom price file → Run workflow.

## Автоматическое обновление

Расписание лежит в файле:

```text
.github/workflows/update_drom_price.yml
```

Сейчас там стоит 4 запуска в день. Время задаётся в UTC.

## Ограничение

Это бесплатный вариант без отдельного VPS. Для старта он подходит. Если Дром не сможет забирать файл с GitHub Pages или появятся ограничения, тогда переносим эту же программу на VPS/сервер.
