# Авито: прогресс по всем 22 категориям

## Режим работы

По просьбе пользователя — небольшие партии **по 5 артикулов**, один проверочный запуск за раз. Категории и манифест исходных 95 не смешиваются. Новые объявления требуют подтверждённых OEM, применимости, реального фото, свежей персональной цены и положительного остатка в Иркутске со сроком 0 дней. Проверка партии сама по себе не публикует XML.
