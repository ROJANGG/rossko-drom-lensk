## Формирование Excel для Авито

Ветка `feature/avito-irkutsk-draft` содержит два этапа:

1. `python avito_irkutsk.py --confirm-irkutsk-source` — создаёт список кандидатов `output/avito_irkutsk_candidates.csv` из **свежего** XLSX РОССКО.
2. Скопируйте `output/avito_irkutsk_candidates.csv` в `input/avito_approved.csv`, затем проверьте каждую строку и заполните поля подтверждений. Образец заголовков также есть в `input/avito_approved.example.csv`. Поля: `approved`, `pickup_confirmed`, `condition_confirmed` — значения `yes` только после реальной проверки; `photo_urls` — проверенные прямые HTTPS-ссылки, разделённые `|`; `fitment` — достоверная совместимость, обязательная для тормозных дисков; `oem_number` — только документально подтверждённый номер.
3. **Выполнено:** два оригинальных XLSX-шаблона Авито загружены в `input/avito_templates/`, их пути уже указаны в `config.json`. Проверка их структуры и генератора включена в GitHub Actions. **Не добавляйте реальные выгрузки и прайсы в публичный репозиторий.**
4. `python avito_feed.py --confirm-irkutsk-source` — заново получает свежий прайс, повторно проверяет наличие и формирует `output/avito_irkutsk/avito_irkutsk_steering.xlsx` и/или `avito_irkutsk_brakes.xlsx`. Без оригинальных шаблонов возможен только технический тест с `--allow-generated-template`; такую копию обязательно проверяйте через инструмент Авито.

При отсутствии подтверждённых позиций XLSX **не формируются**. Генератор не отправляет объявления, не включает расписание и пока не реализует безопасное снятие существующих объявлений. Перед автоматизацией нужно проверить правила обновления и снятия объявлений Авито на небольшом наборе. Наличие РОССКО и готовность выдачи по адресу — разные проверки.

Адрес выдачи: **г. Иркутск, ул. Каховского, д. 11/1** (подтверждён пользователем). Выгрузка Дрома остаётся без изменений.

**Внимание:** колонка `Применимость` из РОССКО носит справочный характер; её нужно проверить и скопировать в `fitment` только после подтверждения по каталогу. Оставляйте `approved` пустым для неподтверждённых позиций.

## Пробная выборка из текущего РОССКО

Workflow `.github/workflows/avito_live_pilot.yml` запускает свежую загрузку XLSX и отбирает по 25 товаров каждой из двух групп. Результат хранится в GitHub Actions как временный архив `avito-irkutsk-review-pilot`, срок хранения — 1 день. **Этот архив не нужно загружать на Авито**: это список для проверки фотографий, применимости и выдачи.

Категории определяются строго по началу описания «Рейка рулевая» / «Рулевая рейка» или «Диск тормозной» / «Тормозной диск». Очистители, сайлентблоки, ремкомплекты, инструмент и расходники не должны попадать в выборку.

Запуск 15.10.2026 после исправления фильтра нашёл 90 реек, 1039 дисков, отобрал 50 строк (25+25), из них 23 со ссылкой на фото для ручной проверки. Это снимок на время запуска, не гарантия текущего наличия в будущем.

Следующий этап: пользователь подтверждает фото и данные по 50 карточкам в отдельной таблице; только после этого `avito_feed.py` выпускает XLSX по оригинальным шаблонам. До подтверждения никакие объявления автоматически не публикуются.

## Закреплённая пробная партия — 50 артикулов

Пользователь выбрал для пробного размещения 25 рулевых реек и 25 тормозных дисков по перечню от 15.10.2026. Точный набор сохранён в `input/avito_pilot_articles.csv` (пары `brand;article`). Workflow `avito_live_pilot.yml` при каждом запуске **заново** получает прайс РОССКО и отбирает только позиции из этого списка; исчезнувшие из наличия товары не заменяет другими. Повторный запуск 15.10.2026 подтвердил наличие всех 50 на момент проверки.

Рабочие Excel-предпросмотры получены из оригинальных шаблонов Авито и исходного CSV отдельно. **Не считать их опубликованными объявлениями или полностью подтверждённой автозагрузкой.** В CSV 23 ссылок-кандидатов на фотографии, 27 товаров без фото. Прежде чем отправлять на Авито, требуется подтвердить право использовать изображения и соответствие артикулам, состояние и совместимость, а также заново проверить остатки.

Заполните их только после предметной проверки. Текущий `avito_feed.py` не публикует объявления при отсутствии подтверждений. **Не коммитьте CSV или фотографии в публичную ветку.**

- Из товаров с успешно открывающимися фотографиями выбираются 25 рулевых реек и 25 тормозных дисков; технические чертежи и сомнительные изображения, замеченные при просмотре пробной контактной ведомости, исключены.
- **Новый список артикулов** сохранён в `input/avito_pilot_articles.csv`. Список не расширяется автоматически новыми товарами: при повторной проверке отсутствующие позиции пропускаются.
- Полный проверочный пакет с 50 фотографиями (CSV + контактный лист) доступен во временном артефакте GitHub Actions `avito-50-with-photos-review`; срок хранения 2 дня. Отдельный просмотренный пользователем Excel для проверки создаётся вне публичного репозитория.
- Изображения технически загружаются и визуально похожи на соответствующие группы запчастей, но **точное соответствие артикулу, право на использование и достоверная применимость не подтверждены автоматически**. Одобрение карточек запрещено до проверки этих данных.
- `avito_feed.py` по-прежнему не создаст итоговые карточки, если поля `approved`, `condition_confirmed` и `pickup_confirmed` не заполнены; для тормозных дисков требуется `fitment`.
- Объявления **не были опубликованы** на Авито. При автоматическом обновлении необходимо дополнительно обеспечить снятие объявлений с нулевым остатком.

## Разрешение на фотографии РОССКО

15 октября 2026 года продавец подтвердил в чате, что РОССКО разрешает ему использовать фотографии товаров для объявлений Авито. Основание — сообщение продавца, не независимая проверка письменного договора. Это снимает необходимость запрашивать у продавца повторное устное подтверждение, но не подтверждает, что каждая конкретная фотография соответствует конкретному артикулу, и не заменяет требования Авито к контенту. Для изображений от иных правообладателей нужны отдельные основания.

## Текущая независимая проверка

`avito_catalog_audit.py` сверяет URL фотографий с карточками конкретных артикулов РОССКО и выгружает только отчёт для проверки. Его статус не подменяет проверку применимости по OEM-каталогам и не подтверждает физическое наличие товара по адресу выдачи. Автопубликация отключена.

## Подтверждение самовывоза и дальнейшее редактирование

15.10.2026 продавец подтвердил возможность получить выбранные запчасти сразу в пункте выдачи: г. Иркутск, ул. Каховского, 11/1. В `avito_pilot_confirmations.json` отмечена возможность немедленной выдачи **со слов продавца**; это не отменяет проверки остатков перед выгрузкой. Для пробной партии `avito_prepare_preflight.py` указывает `Состояние = Новое` и `Доступность = В наличии`, только если соответствующие SKU найдены в свежем прайсе РОССКО с положительным местным остатком и сроком 0.

Редактировать опубликованные объявления следует через **тот же уникальный идентификатор объявления** (`stable_id()` из `avito_feed.py`), чтобы обновлялись текущие карточки, а не создавались дубликаты. После включения автоматической загрузки изменения вручную в кабинете могут быть перезаписаны следующей выгрузкой; главный источник цен, описаний и изображений должен быть один. Перед включением автоматизации ещё нужно отладить снятие предложений, отсутствующих на складе, и проверить успешный импорт по отчёту Авито.

Текущие файлы `PREVIEW_*_NOT_FOR_UPLOAD.xlsx` остаются **проверочными**, без автоматической публикации: применимость и точное соответствие фото артикулу не подтверждены независимо по всем 50 позициям.
