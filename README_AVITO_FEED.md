## Формирование Excel для Авито

Ветка `feature/avito-irkutsk-draft` содержит два этапа:

1. `python avito_irkutsk.py --confirm-irkutsk-source` — создаёт список кандидатов `output/avito_irkutsk_candidates.csv` из **свежего** XLSX РОССКО.
2. Скопируйте `output/avito_irkutsk_candidates.csv` в `input/avito_approved.csv`, затем проверьте каждую строку и заполните поля подтверждений. Образец заголовков также есть в `input/avito_approved.example.csv`. Поля: `approved`, `pickup_confirmed`, `condition_confirmed` — значения `yes` только после реальной проверки; `photo_urls` — проверенные прямые HTTPS-ссылки, разделённые `|`; `fitment` — достоверная совместимость, обязательная для тормозных дисков; `oem_number` — только документально подтверждённый номер.
3. **Выполнено:** два оригинальных XLSX-шаблона Авито загружены в `input/avito_templates/`, их пути уже указаны в `config.json`. Проверка их структуры и генератора включена в GitHub Actions. **Не добавляйте реальные выгрузки и прайсы в публичный репозиторий.**
4. `python avito_feed.py --confirm-irkutsk-source` — заново получает свежий прайс, повторно проверяет наличие и формирует `output/avito_irkutsk/avito_irkutsk_steering.xlsx` и/или `avito_irkutsk_brakes.xlsx`. Без оригинальных шаблонов возможен только технический тест с `--allow-generated-template`; такую копию обязательно проверяйте через инструмент Авито.

При отсутствии подтверждённых позиций XLSX **не формируются**. Генератор не отправляет объявления, не включает расписание и пока не реализует безопасное снятие существующих объявлений. Перед автоматизацией нужно проверить правила обновления и снятия объявлений Авито на небольшом наборе. Наличие РОССКО и готовность выдачи по адресу — разные проверки.

Адрес выдачи: **г. Иркутск, ул. Каховского, д. 11/1** (подтверждён пользователем). Выгрузка Дрома остаётся без изменений.

**Внимание:** колонка `Применимость` из РОССКО носит справочный характер; её нужно проверить и скопировать в `fitment` только после подтверждения по каталогу. Оставляйте `approved` пустым для неподтверждённых позиций.

## Пробная выборка из текущего РОССКО

Workflow `.github/workflows/avito_live_pilot.yml` запускает свежую загрузку XLSX и отбирает по 25 товаров каждой из двух групп. Результат хранится в GitHub Actions как временный архив `avito-irkutsk-review-pilot`, срок хранения — 1 день. **Этот архив не нужно загружать на Авито**: это список для проверки фотографий, применимости и выдачи.

Категории определяются строго по началу описания «Рейка рулевая» / «Рулевая рейка» или «Диск тормозной» / «Тормозной диск». Очистители, сайлентблоки, ремкомплекты, инструмент и расходники не должны попадать в выборку.

Запуск 15.10.2026 после исправления фильтра нашёл 90 реек, 1039 дисков, отобрал 50 строк (25+25), из них 23 со ссылкой на фото для ручной проверки. Это снимок на время запуска, не гарантия текущего наличия в будущем.

Следующий этап: пользователь подтверждает фото и данные по 50 карточкам в отдельной таблице; только после этого `avito_feed.py` выпускает XLSX по оригинальным шаблонам. До подтверждения никакие объявления автоматически не публикуются.
