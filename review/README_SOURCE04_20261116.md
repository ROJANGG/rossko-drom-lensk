# Партия source-04: 100 приводных ремней LYNXauto

## Итог проверки 16 ноября 2026

**85 позиций** одновременно имеют подтверждённые OEM, применимость производителя, реальную точную фотографию и положительную свежую персональную API-проверку ROSSKO в Иркутске со сроком 0 дней. Это **черновая партия**, не опубликованная в действующем фиде.

По API: первоначально подтверждены 93 из 100, по трём возникли сетевые ошибки, четыре не прошли свежую проверку остатка. Отдельный повтор только трёх сетевых ошибок подтвердил все три: итог **96 API-положительных**, 4 — без свежего подтверждения нужного остатка.

По источникам после одной ограниченной попытки восстановления неответивших страниц: OEM получены для 96 точных SKU, таблицы применимости — для 91, реальные фотографии — для 90. Все 90 фото просмотрены; оригинальные байты проверены по SHA256, размеры и JPEG/PNG проверены. Повторов SHA256 среди этих изображений нет. Совместное пересечение всех обязательных проверок — **85**.

| Основная причина блокировки оставшихся 15 | Количество |
| --- | ---: |
| Не подтверждена применимость производителя | 5 |
| Не подтверждён точный SKU/OEM в первичном источнике | 4 |
| Нет свежего подтверждения нужного остатка/API | 4 |
| Не подтверждён точный файл реального фото | 2 |

Каталог LYNXauto — первичный источник. На каждой странице проверено точное совпадение MPN, OEM берётся из таблицы «OE No.», а не из таблицы аналогов. Применимость получена по ссылке самого товара на таблицу производителя. Фото связаны с той же карточкой и сверены визуально, включая артикулы на упаковках. Сохранены исходные ссылки, SHA256 страниц/таблиц/фото и индивидуальные времена проверок. Подмены другим брендом, чертежами или заглушками не делались.

## Файлы для подготовки следующего выпуска

- `avito_source04_verified_candidates_20261116.csv`: 85 позиций, OEM, применимость, розничная цена, фото, SHA256 и время API.
- `AVITO_SOURCE04_REVIEW_ONLY_NOT_LIVE.xml`: **только 85 новых карточек**, без действующих 245. Это не полный файл для замены текущей автозагрузки.
- `../input/avito_source_batch04_20261116.json`: подробный результат по всем 100, включая блокировки и отдельные исходные времена проверки.

Черновик содержит предложенную классификацию `SparePartType=Двигатель`, `EngineSparePartType=Приводные ремни, натяжители`; значение найдено в справочнике текущей интеграции XML for Avito. Этот черновик ещё не проходил импорт/модерацию Авито.

Перед фактическим выпуском потребуются: интеграция новой категории и точных SKU в регулярное обновление, свежий API-контроль цены/остатка/0 дней, размещение оригинальных фото на проверенном публичном хосте с контролем SHA256 и проверка добавления к действующему XML без изменения старых карточек. Сам черновик не менял действующий XML. Все розничные цены имеют своё время API-проверки; закупочные цены и ключи в файлах отсутствуют.
