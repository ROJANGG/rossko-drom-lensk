# Росско → Дром v0.4

Версия под схему с постоянной ссылкой для Дрома.

## Как работает

1. Программа скачивает актуальный XLSX-прайс Росско по ссылке из `config.json`.
2. Перезаписывает локальный файл `input/rossko_price.xlsx`.
3. Обрабатывает все товары, у которых есть цена и остаток.
4. Ставит наценку 37% и округляет цену вверх до 50 ₽.
5. Во всех строках ставит статус `Под заказ`.
6. Для Ленска рассчитывает сроки:
   - если срок Росско `0`, ставит `2-5 дней`;
   - если срок Росско больше `0`, ставит `срок Росско + 2` — `срок Росско + 5` дней.
7. Записывает применимость в `Примеч.`.
8. Создаёт один и тот же файл `public/drom_lensk.xlsx`.
9. Этот файл можно отдать Дрому по постоянной ссылке.

## Простая логика обновления

Каждый запуск пересобирает файл заново. Никакого сравнения версий, хэшей и сложного кэша нет.

Оставлена только базовая проверка: если вместо Excel скачалась ошибка или пустой файл, рабочий прайс не перезаписывается.

## Настройки

Основные настройки в `config.json`:

- ссылка на прайс Росско;
- данные продавца;
- наценка;
- округление цены;
- профиль города Ленск;
- будущие профили городов.

## Локальный запуск

1. Установить Python 3.11+.
2. Распаковать архив.
3. Запустить `run_update.bat`.
4. Готовый файл появится здесь:

```text
public/drom_lensk.xlsx
```

## Локальный сервер

Запустить:

```text
run_server.bat
```

Локальная ссылка:

```text
http://localhost:8080/price/drom_lensk.xlsx
```

Дром эту ссылку не увидит, потому что `localhost` доступен только на этом компьютере. Для Дрома нужен сервер или бесплатный хостинг.

## Бесплатное размещение

Смотри файл:

```text
README_FREE_HOSTING.md
```

Там описан вариант через GitHub Actions + GitHub Pages: без VPS, с автообновлением по расписанию и постоянной ссылкой для Дрома.
