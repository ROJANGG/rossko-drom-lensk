# Авито: полный поиск по 22 категориям

Запущена обработка полного снимка кандидатов, а не очередной ручной партии. [Живой прогресс](https://github.com/ROJANGG/rossko-drom-lensk/blob/avito-expansion-review/results/20261113/PROGRESS.md) и [машинная сводка](https://github.com/ROJANGG/rossko-drom-lensk/blob/avito-expansion-review/results/20261113/summary.json) обновляются в отдельной ветке после каждой порции до 100 позиций. [Запуск GitHub Actions](https://github.com/ROJANGG/rossko-drom-lensk/actions/runs/43438291025).

## Объём свежего снимка

13 ноября в 16:58 МСК загружен свежий прайс: 45 711 строк, 13 055 уникальных кандидатов с положительным остатком и 0 дней в запрошенных категориях. Из них 47 уже есть в действующем XML и исключены. Замороженная очередь нового поиска — **13 008 SKU**. Прежние 13 015 были более ранним снимком прайса, а не фиксированным планом публикаций; уменьшение на семь не связано с новыми публикациями.

135 точных результатов, полученных менее часа назад, переиспользованы с их настоящим временем проверки. Они не выданы за новые API-запросы. По остальным выполняется свежий поиск. Отдельно сохраняется список неоднозначно классифицированных позиций для ручной проверки.

## Что означает «подходит»

1. Точный бренд и артикул; положительный остаток; API явно подтверждает Иркутск и срок 0 дней.
2. Подтверждённая персональная цена; в результат записывается только рассчитанная розничная цена Авито, без закупочной цены.
3. Проверенные OEM, применимость и реальная фотография именно этого изделия. Прежде чем объявление попадёт в XML, этот этап и свежесть API должны быть подтверждены.

Текущий длительный запуск выполняет **первый этап полного отбора**, а не автоматически подтверждает источники и фотографии. Файл `API_zero_day_candidates_REQUIRE_SOURCE_REVIEW.json` содержит кандидатов для второго этапа; название и флаг `not_approved_for_publication` явно запрещают считать его списком готовых объявлений. Окончательный список готовых к публикации пока не сформирован. Отсутствие положительных результатов в незавершённой проверке не означает, что подходящих позиций нет во всём каталоге.

## Нагрузка, сохранность и продолжение

Максимум два одновременно обрабатываемых SKU; начала поисковых запросов разнесены минимум на одну секунду. При пяти подряд сетевых сбоях обработчик останавливает новые обращения и сохраняет контрольную точку. Тайм-ауты и непроверенные ответы не обозначаются как отсутствие товара. Повторный запуск того же задания продолжает замороженный список, пропуская сохранённые успешные проверки и повторяя сетевые ошибки.

Состояние записывается после каждой порции до 100 позиций, поэтому аварийное завершение может потребовать повторить лишь незаписанный хвост. Состояние RUNNING в файле относится к указанному времени последней записи; фактическое состояние процесса видно на странице Actions. Один проход может занимать несколько часов, лимит задания — 330 минут. Если он прервётся, сохранённые порции остаются доступны.

Действующий XML, IDs, цены и фотографии существующих объявлений этот поиск не изменяет. Все записи идут только в ветку `avito-expansion-review`; обычные обновления Авито работают в своей группе. Покупные цены, API-ключи и сырые SOAP-ответы не публикуются. Результаты имеют индивидуальные временные метки и не являются одновременным снимком всех остатков. Перед публикацией потребуется повторная свежая проверка.

Локально прошли семь защитных тестов и интеграционная проверка отбора по прайсу; в Actions также выполняются эти семь тестов перед обращением к API. Проверяются 22 категории, отсутствие подмены SKU при возобновлении, запрет выдавать цену с другим сроком за подходящую, исключение закупочных цен и ограничение свежести переиспользуемых результатов.
